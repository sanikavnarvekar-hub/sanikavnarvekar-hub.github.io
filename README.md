# Sanika Narvekar | Portfolio

Personal portfolio website of Sanika Narvekar, B.Sc. Forensic Science undergraduate at Lovely Professional University.

**LinkedIn:** https://www.linkedin.com/in/sanika-narvekar-836043429

## Stack
Plain HTML, CSS and JavaScript. No build step, so it works directly on GitHub Pages.

## Deploy on GitHub Pages
1. Create a new public repository named `sanika-narvekar.github.io` (or any name, e.g. `portfolio`).
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the repository root.
3. Go to **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After a minute the site is live at `https://<your-username>.github.io/` (or `https://<your-username>.github.io/portfolio/` for a differently named repo).

## Run locally
Open `index.html` in a browser.
